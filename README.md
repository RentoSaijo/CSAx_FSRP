# CSAx 2024–25 rankings

This public site presents the 2024–25 CSAx rankings for eligible NHL forwards and defensemen. It is the destination for the QR code on the Connecticut College Funded Sophomore Research Program poster.

The page contains derived rankings and a description of the method. It does not contain raw All Three Zones data, scouting passages, or private research inputs. The underlying research repository remains private.

The site is published through GitHub Pages from the repository root on `main`.
